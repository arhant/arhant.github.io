Message-level encryption for the Amazon launch

Designing JWE/JWS message-level encryption on top of TLS for Finance Services APIs, with key management in AWS KMS.

Where
Cox Automotive · Finance Services
My part
Designed the encryption and key management
Driver

In short

Amazon's production launch set security requirements for Finance Services APIs beyond transport-level TLS. I designed message-level encryption (JWE/JWS) on top of TLS, and defined key management with AWS KMS, key rotation, and partner onboarding, with backward compatibility. The design is backed by a full automated security test suite.

Context

Cox Automotive's Finance Services division builds the credit application, lender connectivity, contracting, and document signing platforms used by about 10,000 US dealerships and major lenders, and works with partners including AutoTrader, VinSolutions, Amazon, RouteOne, Honda, and Subaru.

Amazon's production launch set security requirements for the Finance Services APIs that went beyond transport-level TLS.

Why encrypt the message as well as the connection

TLS protects data while it travels between two endpoints. Message-level encryption protects the message itself: a JWS (JSON Web Signature) lets the receiver check who sent a message and that it was not changed, and a JWE (JSON Web Encryption) keeps its contents readable only by the holder of the decryption key.

What I did

  • Designed message-level encryption (JWE/JWS) for Finance Services APIs, layered on top of TLS.
  • Defined key management with AWS KMS, including key rotation.
  • Defined partner onboarding for the new scheme.
  • Kept it backward compatible.
  • Backed it with a full automated security test suite.

The request path, step by step

  1. The partner's client signs the request payload as a JWS.
  2. It then encrypts the signed payload as a JWE. Signing first and encrypting second is the usual order for nested JSON Web Tokens (RFC 7519).
  3. The encrypted message travels inside a TLS connection, as before.
  4. The Finance Services API decrypts the message and verifies the signature. Key management uses AWS KMS, with key rotation.

Result

Designed to meet Amazon's production launch security requirements, with backward compatibility, and backed by a full automated security test suite.
